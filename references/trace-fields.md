# User-visible trace fields

Show action history, not hidden reasoning. Include workspace and version IDs; query text/source; retrieved-at time; source tier, URL, and locator; lifecycle/status confidence; canonical/dedup decision; eligibility and match explanations; failures; and run counts.

Exclude full resume text, credentials, cookies, access tokens, sensitive demographic information, and private contact details unless the user explicitly needs a minimal item shown. Redact unnecessary PII in summaries and exports. State `fact`, `inference`, or `unknown` where that distinction changes a decision.
